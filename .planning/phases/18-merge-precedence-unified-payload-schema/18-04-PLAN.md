<objective>
Map the four 12Z-native sources — `spc-convective`, `spc-fire`, `wpc-ero`, `wpc-wssi` — onto the grid
days their own day indices already equal (D-11), apply each source's no-risk floor at entry-creation
time (D-13), and record per-source, per-day reporting state so "did not report" stays distinguishable
from "reported below floor".

Purpose: this is where D-01's shared-in-memory-values constraint is hardest and most load-bearing.
`spc-convective` and `spc-fire` predate the registry (14 D-08): there is no `results.<id>.payload` for
them, only about a dozen individually-named locals. They are also exactly the two dimensions
(`convective`, `fire`) that need real two-source suppression in plan 18-05, so this cannot be written
as one generic accessor loop.

Output: two grid-assembly methods, per-source stale attribution for the SPC inline block, and the
`reportedDays`/`activeDays` accumulators plan 18-05 resolves precedence against.
</objective>

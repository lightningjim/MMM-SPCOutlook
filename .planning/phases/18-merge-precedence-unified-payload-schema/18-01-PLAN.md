<objective>
Create `hazardTaxonomy.js`: the single static artifact that maps every `(source, label)` pair
to a hazard dimension, declares the precedence order per dimension, and declares the no-risk
floor per day-scoped source.

never done by label-string matching. D-06 locks this to a standalone module holding the
precedence table beside the map. Every later plan in this phase reads from this file; nothing
else in the phase may restate a dimension, a rank order, or a floor.

Output: `hazardTaxonomy.js`, a pure static-config CommonJS module with no `this`, no network,
no logic beyond lookup and load-time validation.

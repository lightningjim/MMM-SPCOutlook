## Deferred item closed — Typography's replaced sentence, quoted for the reviewer

Per this plan's own `<output>` requirement, the exact replacement text for the "never on an
ancestor or a sibling" sentence (`19.1-UI-SPEC.md`'s Typography section):

> **Scoped to `color` only, going forward:** the original sentence read "never on an ancestor or a
> sibling" with no qualification. It now applies to `color` alone, which still lives on a single
> carrier (`detailColoredWrapper`, via `display:contents`) and is never declared on an ancestor or a
> sibling of the cells it colours. It makes no claim about `font-family` any longer, because no
> length anywhere in this markup resolves against one.

This closes `19.1-05` Task 3 part (e) (explicitly scoped there and deferred) and the anti-pattern
`19.1-VERIFICATION.md`'s Anti-Patterns Found row 2 recorded against it. The two-step history (plan
`19.1-03` deliberately declaring `font-family` at row level, contradicting the original sentence,
to resolve the `also:` spacer's `ch` need; then plan `19.1-06` removing `font-family` from the
detail markup entirely because grid tracks resolve against no font at all) is recorded in the
paragraph immediately above this one, and the visible consequence (detail rows now render in the
host's proportional font again, reversing `19.1-03`'s accepted monospace change) is flagged, not
approved, for plan `19.1-09`'s live observation.

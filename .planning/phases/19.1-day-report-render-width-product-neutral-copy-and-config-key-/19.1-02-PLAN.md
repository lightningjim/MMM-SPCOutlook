<objective>
Surface an unrecognised config key to the operator instead of silently absorbing it (19-UAT.md test
13), with a nearest-`defaults` suggestion — the one thing that would have saved the 2026-09-09 UAT
session when `dayReportDetails` (plural) was silently ignored against `dayReportDetail`.

Purpose: MagicMirror builds `this.config` as `Object.assign({}, this.defaults, data.config)` with no
validation, so a typo'd key is absorbed and never read. The operator believed detail mode was on
when it never was — it cost real debugging time AND invalidated a prior width observation (the
defect this phase's plan 03 fixes was re-measured because of it).

Output: a `_warnUnrecognizedConfigKeys()` validator called once from `start()`, a ~15-line
dependency-free Levenshtein nearest-match helper, and three mutation-proven probe scenarios.
</objective>

## A second live false negative this plan must fix

`getDom`'s no-risk short-circuit (MMM-SPCOutlook.js:154-186) has **no `this.mds` term**. The advisory
render block sits at line 210, *inside the else branch*, which the gate never reaches when every
other product reads NONE. So today, a location inside an active Mesoscale Discussion with no
convective risk, no fire weather risk and no ERO risk renders the literal string
`"No Severe Weather Risk"` and the MD is never shown.

That is dormant for SPC MDs — which usually accompany convective risk — but it is squarely fatal for
MPD-01, because an MPD is a *precipitation* discussion and routinely fires with zero SPC convective
risk. Shipping the MPD product without extending this gate would deliver a feature that is invisible
in exactly its most common case. Task 2 fixes it and plan 15-09 pins it with a scenario.
</critical_context>

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Vacuous probe scenario | A new scenario can assert on something no code path can produce, so it passes forever and proves nothing. Hit twice this session: (1) 15-05's mutation 5 produced **zero** RED scenarios — the fixture was silently vacuous until a render assertion was added; (2) 15-02's KMZ round-trip scan was vacuous because `adm-zip` sorts entries alphabetically by default, so the entry-order coverage never actually ran. | blocking | Mutation-proof every new scenario individually (D-10): break the exact line it covers, confirm RED **with a diagnosable message**, restore. A scenario that stays GREEN under its own mutation is a fixture defect to fix, not a pass. Both remaining plans (15-08, 15-09) are scenario-writing plans, so this gates them directly. |
| Stale worktree base on executor start | Every one of the 6 executor agents this session started with HEAD at a stale base (usually phase-14's `28845fa`) rather than the wave base passed in the prompt. Each corrected it, but an agent that skipped the check would have silently built on pre-wave code. | advisory | The `worktree_branch_check` block at the top of each executor prompt already catches this — keep passing the explicit `EXPECTED_BASE` SHA and keep the check as the agent's literal first action, before any file read. |
| Assuming a documented value domain matches the live feed | D-09 was written around a `LIMITED` WSSI tier that does not exist in WPC's data. Any code or fixture keyed to that string would have been unreachable. | advisory | Verify value domains against the live endpoint's own `drawingInfo.renderer` / schema before writing conditionals or fixtures against them. |

  `WINTER WEATHER AREA → MINOR → MODERATE → MAJOR → EXTREME` (ALL CAPS, field `impact`).

  no-polygon. Recorded as an AMENDED block in `15-CONTEXT.md` (commit `d1afcc2`).
- **MPD recency pre-filter is a cost optimization only.** ~48h `Last-Modified` pre-filter on the
  directory listing; the authoritative active/inactive decision is each candidate's own
  `ValidEndTi`, evaluated unconditionally. Letting the pre-filter decide inclusion would
  reintroduce a false-negative class.

  given up coverage of `extractSoleKmlEntry`'s `doc.kml` selection, togeojson's
  description-object shape, and `fetchBinBuffer`'s binary path.

  happened.

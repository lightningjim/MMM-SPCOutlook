<objective>
Build `_runHeatRiskProduct` — the fetch/reproject/zip/sort/dedupe/bucket/freshness pipeline — with a
clock-independent cache contract, and wire it into `getSpcOutlook`'s payload.

Purpose: this is HeatRisk's whole backend. It is the milestone's only non-polygon, turf-free
product: one HTTP round-trip returns a 7-entry mosaic catalog whose ordering is arbitrary
(live-observed `2,4,5,7,1,3,6`) and whose top-level `value` tracks whichever tile ArcGIS considers
visible (live-observed pointing at Day 2, not Day 1). Every day attribution therefore comes from
sorting `idp_validtime`, and every staleness signal from D-04/D-05/D-07's deliberately
distinguished failure shapes.

Output: `node_helper.js` gains a cache-write/read pair, one runner, and one payload key.
</objective>

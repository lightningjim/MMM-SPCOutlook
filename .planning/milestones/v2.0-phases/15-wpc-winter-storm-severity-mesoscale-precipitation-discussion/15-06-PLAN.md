<decision_record>
## Orchestrator-resolved decisions this plan implements

**MPD-04 tie-break (Claude's Discretion in CONTEXT.md, resolved by research).** WPC publishes no
active index. The authoritative "is this still active" decision is each candidate's own `ValidEndTi`
resolved against its `IssueTime`, evaluated unconditionally. Filename number is never used for
selection.

**Open Question 2 — the Last-Modified pre-filter.** Use a generous 48h pre-filter on the directory
listing purely as a fetch-count optimization. It must never be the sole inclusion or exclusion gate;
that would reintroduce the false-negative class. Every candidate that survives the pre-filter is
still judged on its own `ValidEndTi`, and an entry whose listing timestamp cannot be parsed is
**kept**, not dropped.

**Fail-open direction.** Where validity genuinely cannot be established (unparseable `IssueTime`,
unknown timezone abbreviation, missing `ValidEndTi`), the candidate is kept and the miss is logged.
The project's core value is no false negatives; showing an expired MPD is a minor annoyance, hiding
an active one is the failure this product exists to prevent.
</decision_record>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote directory-listing HTML → fetch target | An Apache index page is parsed for strings that become outbound requests. This is the new SSRF surface in this phase. |

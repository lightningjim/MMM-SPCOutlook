Build the regression guard that the existing `rpt03-*` scenarios failed to be: pin the ABSENCE of the
defective construct and the PRESENCE of both width contracts, so the UAT-5 defect cannot ship green
a second time.

scenarios asserted character POSITIONS — which is not what broke. Nothing automated can prove the
region no longer overlaps (no layout engine exists in this harness, and `jsdom`/`linkedom` both
document that they do not implement CSS layout), but three things ARE machine-checkable and were not
checked: that no literal space-run padding reaches the markup, that the `min-width:Nch` declarations
are present and correctly derived, and that BOTH wrapper style contracts are set.

an honest record of what remains `MANUAL ONLY`.

<objective>
Remove the `if (!extended)` early-return fork from `getSpcOutlook` so the backend payload has exactly one shape (CFG-02, D-01).

Purpose: Today `getSpcOutlook` returns a structurally different object depending on config — the `!extended` branch omits `day4`-`day8` and `day48Risk` entirely and hardcodes `fireWeather.day3Risk`-`day8Risk` inline. That fork is the anti-pattern this milestone exists to remove: with six product toggles arriving across Phases 14-17, a payload that forks per flag becomes many shapes, and Phase 18's merge logic would have to null-check every product key. This plan collapses the fork to one return, establishing the "declare defaults, conditionally fetch, always return" rule that plan 14-03 then applies verbatim to `excessiveRain`.

Output: `node_helper.js` with one success-path `return` in `getSpcOutlook`, plus captured payload key-set evidence proving the shape no longer forks.

**This is the single riskiest edit in the phase.** It touches production code shipped across four milestones with no automated tests. Preserve every existing value expression exactly; the only structural changes are *where* things are declared and *what* is gated.
</objective>
